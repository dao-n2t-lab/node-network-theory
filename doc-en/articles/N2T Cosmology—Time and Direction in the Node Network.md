## I. The Essence of Time: A Measure of Changes in the Node Network State

In the N2T framework, time is not an independently existing dimension, but a measure of changes in the node network state.

### 1.1 Time as an "Iteration Counter"

Each node executes a "receive-update-send" cycle. One synchronized iteration of all nodes across the entire network corresponds to a fundamental time step:

$$\Delta t \propto \text{the average time required for all nodes to complete one iteration}$$

The rate of time flow in the universe is determined by the average iteration speed of all nodes in the network. The faster the node network state changes (the higher the vibration frequency), the faster time flows; the slower the state changes, the slower time flows.

### 1.2 Time Is Not a Presupposed Dimension

In the N2T framework, time is not a pre-existing "stage," but a byproduct of the node network's operation:

| Standard Physics Concept | N2T Framework Correspondence |
|:---|:---|
| Time as an independent dimension | A measure of changes in the node network state |
| Time flows uniformly | The statistical average of iteration step sizes across all nodes |
| Time dilation | Slowing of local node network iteration speed |
| Irreversibility of time | The directionality of the stress minimization process |

## II. The Arrow of Time: The Directionality of Stress Minimization

The source of the arrow of time is: in the stress minimization process of the node network, changes in local states are irreversible—node clusters that have converged to a stress minimum will not spontaneously return to a high-stress state.

### 2.1 Why Is Stress Minimization Unidirectional?

In the N2T framework, the node network always evolves toward stress minimization. This directionality is structural, not statistical:

- When a node cluster forms (such as a nucleus, star, or galaxy), the edges between nodes are locked in a stable stress balance;
- Disassembling a locked node cluster requires a large input of energy, far exceeding the energy released during its natural evolution;
- In its natural state, the system does not actively choose a high-stress state.

This irreversibility of "locking-unlocking" is the source of the arrow of time.

### 2.2 Entropy and the Node Network State

In standard physics, entropy is a measure of the degree of disorder in a system. In the N2T framework:

- **High-entropy state**: node distribution tends to be uniform, phases tend to be random, stress tends to be dispersed;
- **Low-entropy state**: nodes are concentrated, phases tend to be ordered, stress tends to be concentrated.

The transition from low entropy to high entropy is the direction of the arrow of time. But the difference between the N2T framework and standard physics is: this direction is structural, not statistical—the phase locking and stress concentration of the node network naturally tend to evolve toward the low-entropy direction, while the nodes released by phase unlocking naturally tend to diffuse toward the high-entropy direction; both directions together constitute the complete arrow of time.

### 2.3 The Relationship Between Stress Minimization and Entropy Increase

| Standard Physics | N2T Framework |
|:---|:---|
| Entropy increase defines the direction of time | The directionality of stress minimization defines the direction of time |
| Entropy increase is irreversible | Stress concentration/release alternate, but each concentration and release has directionality |
| Entropy increase is statistical | The direction of time is structural |

## III. The Relativity of Time

In the N2T framework, the rate of time flow is not uniform, but depends on the local state of the node network.

### 3.1 Higher Node Density Means Slower Time Flow

In high-density regions (interiors of stars, near black holes):

- The edges between nodes are compressed, increasing the propagation delay $\tau_{ij}$；
- The time required for nodes to complete one "receive-update-send" cycle is longer;
- Therefore, the rate of time flow in these regions is slower than in low-density regions.

**Gravitational time dilation, in the N2T framework, corresponds to an increase in node propagation delay.**

### 3.2 Lower Node Density Means Faster Time Flow

In low-density regions (interstellar space, vacuum):

- The edges between nodes are at natural length, with smaller propagation delay $\tau_{ij}$；
- The time required for nodes to complete one cycle is shorter;
- Therefore, the rate of time flow in these regions is faster than in high-density regions.

### 3.3 The N2T Formula for Time Dilation

The time dilation factor $\gamma$ can be expressed as a function of node density:

$$\gamma \propto \frac{\tau_{\text{high}}}{\tau_{\text{low}}} \approx \frac{L_{\text{high}}}{L_{\text{low}}} \cdot \frac{\nu_{\text{low}}}{\nu_{\text{high}}}$$

**Time dilation is not the result of "spatial curvature," but the macroscopic manifestation of differences in node propagation delay.**

## IV. The Directionality of Time: The Asymmetry of Past and Future

### 4.1 Why Can We Only Remember the Past?

In the N2T framework, "memory" is the stress trace in the node network:

- After an event occurs, it leaves identifiable phase changes in the node network;
- These phase changes are "frozen" in the local structure of the network after the event (such as connection states of brain neurons, deformation traces of physical objects);
- These traces cannot be "read in reverse order"—the node network does not automatically restore the phase distribution that existed before the event.

**The unidirectionality of time comes from the recordability of phase changes in the node network, and this recording is irreversible.**

### 4.2 The Uncertainty of the Future

The future state is not predetermined because:

- The evolution of the node network is driven by stress minimization, but there is uncertainty in the local stress distribution;
- Phase coupling between nodes makes the network state path-dependent—different evolutionary paths may lead to different macroscopic outcomes;
- The past is "frozen" phase records; the future is "unfrozen" potential phase states.

### 4.3 A Unified Statement of the Arrow of Time

In the N2T framework, the essence of the arrow of time is:

**The directionality of phase locking in the node network—the evolutionary path from dispersion to concentration, from independence to coupling, from high stress to low stress—is structural and irreversible. This irreversibility defines the unidirectionality of time.**
