## I. The Starting Point: Superposition—Multiple Phase Paths Simultaneously Active

### 1.1 The Geometric Definition of Superposition

In the N2T framework, a superposition state corresponds to: **multiple phase-synchronized paths in the system's node network being simultaneously active, with fixed relative phase differences between each path.**

For example, an electron standing wave on a shell-layer grid may simultaneously have multiple possible phase distribution modes—each mode corresponds to an eigenstate. These modes coexist in the node network, forming a superposition state.

### 1.2 Stability Conditions for Superposition

The maintenance of a superposition state requires:

- The relative phase differences between paths remain constant;
- External perturbations are insufficient to破壞 the phase locking between paths;
- The system's node network is in a low-stress state, capable of accommodating the coexistence of multiple paths.

## II. Entanglement: Generation and Retention of Phase Memory

### 2.1 The Geometric Definition of Entanglement

When two node clusters (or two systems) have previously shared the same closed loop, the topological phase of that loop is "frozen" into each of their respective node networks.

In a superposition state, multiple phase paths are simultaneously active, meaning the system's phase information is distributed across multiple paths. If, during evolution, the system's node network couples with an external node network through a homologous closed-loop path, two or more phase paths will "record" the same topological information in the node network, forming an entangled correlation.

### 2.2 The Relationship Between Superposition and Entanglement

- **Superposition**: Multiple phase paths coexist within a single system;
- **Entanglement**: Multiple phase paths span two or more node clusters, and their topological phase memories originate from the same closed-loop sharing.

Superposition is a prerequisite for entanglement—only when multiple paths are simultaneously active can the phase memory of entanglement form.

## III. Decoherence: Randomization of Phase Memory

### 3.1 The Geometric Definition of Decoherence

When the system's node network couples with an external environmental node network, random phase perturbations from external nodes are injected into the system,破壞ing the fixed relative phase relationships between the paths.

### 3.2 Decoherence in a Superposition State

In a superposition state, multiple phase paths coexist. When the system couples with the external environment, decoherence occurs from each path individually:

| Path State | Decoherence Mechanism |
|:---|:---|
| Relative phases of paths fixed | External phase perturbations injected, relative phase differences randomized |
| Each path evolves independently | Each path is "smeared" by external perturbations; superposition degenerates into a mixed state |

Decoherence is the first step in the destruction of the superposition state—it does not directly cause collapse, but it prepares the conditions for collapse.

## IV. Measurement: Execution of Phase Locking

### 4.1 The Geometric Definition of Measurement

Measurement is a strong phase locking between the system's node network and the measurement device's node network—the phase distribution of the system's node network is locked onto a specific phase state of the device's node network.

### 4.2 Measurement in a Superposition State

When a system in a superposition state couples with a measurement device:

1. The multiple phase paths of the system's node network simultaneously "attempt" to establish phase locking with the device's node network;
2. The device's node network can only lock onto one of these paths;
3. The locked path receives the device's phase support; the other paths lose support and begin to decay.

### 4.3 The Difference Between Measurement and Decoherence

In the N2T framework, both measurement and decoherence are results of phase coupling between the system and environmental node networks, but they differ essentially:

| Dimension | Decoherence | Measurement |
|:---|:---|:---|
| Environment type | Random environmental node network (no definite reading) | Measurement device node network (readable) |
| Phase locking strength | Weak to moderate | Strong |
| Result | Mixed state (coherence lost) | A definite eigenstate + reading |
| Information recording | None (information lost to environment) | Yes (information recorded by device) |
| Controllability | Uncontrollable | Controllable (device can be designed) |

**Measurement is a special form of decoherence**: when the external node network is designed to be readable, decoherence manifests as measurement.

## V. Collapse: Completion of Phase Locking

### 5.1 The Geometric Definition of Collapse

Collapse is the irreversible process in which, after the system's node network is phase-locked by the device's node network, the unlocked phase paths are suppressed and the system is "frozen" into one phase state.

In the N2T framework, collapse is not a "wavefunction suddenly shrinking to a point," but rather that after decoherence is complete, the phase memory is occupied by the specific locked path.

### 5.2 The Complete Evolutionary Path

| Stage | State | Node Network Description |
|:---|:---|:---|
| 1. Superposition | Superposition state | Multiple phase-synchronized paths simultaneously active, relative phases fixed |
| 2. Entanglement | Phase memory formation | Topological phase of homologous closed loop recorded in multiple paths |
| 3. Decoherence | Phase relationship破壞ed | External perturbations randomize relative phases between paths |
| 4. Measurement | Phase locking executed | Device node network locks onto one path |
| 5. Collapse | Single eigenstate | Other paths suppressed; system frozen in locked state |

### 5.3 The Unified Picture from Superposition to Collapse

In the N2T framework, the path from superposition to collapse can be summarized as:

$$\text{Superposition} \twoheadrightarrow \text{Entanglement} \twoheadrightarrow \text{Decoherence} \twoheadrightarrow \text{Measurement} \twoheadrightarrow \text{Collapse}$$

This is a continuous evolutionary chain of the node network, with each step having a clear geometric mechanism:

- **Superposition** = coexistence of multiple phase paths
- **Entanglement** = homologous topological phase memory
- **Decoherence** = relative phases randomized
- **Measurement** = strong phase locking occurs
- **Collapse** = phase locking complete, paths frozen

### 5.4 The Irreversibility of Collapse

In the N2T framework, the irreversibility of collapse comes from:

- **Phase information diffusion**: Information from the unlocked phase paths diffuses into the measurement device's node network and cannot be recovered;
- **Degree of freedom gap**: The device's node network has far more degrees of freedom than the system's node network; phase information is "diluted";
- **Temporal directionality**: The directionality of phase locking defines the arrow of time for collapse.

## VII. Summary

In the N2T framework, the unified picture of the core concepts of quantum mechanics is:

A superposition state is the coexistence of multiple phase paths in a node network. When these paths form phase memory through homologous closed loops, entanglement is produced. When external perturbations破坏 the relative phases between paths, decoherence occurs. When the measurement device's node network strongly phase-locks onto one path, measurement occurs. When the other paths are suppressed and the system is frozen in that state, collapse is complete.

**The quantum-to-classical transition is not a mysterious event of "wavefunction collapse," but a continuous process of the node network's phase evolution from multipath coexistence to single-path phase locking.**

In the N2T framework, quantum mechanics no longer requires a "collapse postulate"—it is reduced to the geometric necessity of phase locking and information diffusion.
