## I. Nodes Are Not Isolated Oscillators

Each node is connected to a certain number of neighboring nodes. Every neighbor is vibrating, and each vibration transmits phase perturbations to the node through edges. These perturbations may differ in amplitude, frequency, direction, phase, and chirality.

This means that what the node receives is not a single, pure input signal, but a composite perturbation field that superimposes multiple phases, multiple frequencies, and multiple directions. Each input generates stress on the node, forcing it to adjust its phase state in response.

In a standard physics analogy, this is like a buoy floating on water, being struck simultaneously by waves from all directions—its motion is not simple up-and-down oscillation, but a composite response integrating multiple directions, multiple frequencies, and multiple phases.

## II. The Output Wave Is Not a Stable Single Mode, But Carries Twist

If the perturbations received by a node from different directions are unbalanced (which is usually the case), then the node's own vibration mode is not a simple single-frequency, single-direction, single-chirality oscillator. Under the combined action of stresses from multiple directions, it produces a composite motion mode.

The manifestation of this composite mode in the output wave is: the wavefront is not an ideal spherical wave, but carries features of twist, curvature, and non-uniform phase distribution. Simply put, the wave emitted by the node propagates outward in a "twisted" manner.

| Input Environment | Node State | Output Wave Characteristics |
|:---|:---|:---|
| Symmetrically balanced perturbations from all directions | Stable, low stress | Approximately spherical wave |
| Asymmetric perturbations from all directions | Forced, twisted | Spindle-shaped, spiral, non-uniform phase |
| Presence of chiral preference | Chirally biased | Left-handed or right-handed tendency |

## III. Sources of Asymmetric Perturbations

Asymmetric perturbations in the node network come from multiple levels:

1. **Asymmetric connectivity**: different nodes may have different degrees, resulting in different numbers of received perturbations;
2. **Different phase states of neighbors**: each neighbor's phase may differ, making the input signal non-uniform in phase;
3. **Different edge lengths**: distances to different neighbors vary, causing different signal propagation delays;
4. **Stress gradients**: the stress distribution around a node is spatially non-uniform—some directions have high stress, others low stress;
5. **Differences in energy transmission paths**: the amount of energy transmitted to the node from different directions may vary.

In a real network, these asymmetries are universal; symmetric balance is the exception rather than the rule.

## IV. This "Twist" Is the Direct Source of Spin and Chirality

In standard physics, a particle's spin and chirality (such as the neutrino being only left-handed) are usually regarded as intrinsic properties. But in the N2T framework, they may simply be macroscopic manifestations of asymmetric perturbations in the node network environment:

- When a node outputs waves, if the surrounding phase gradient distribution has a chiral preference (for example, perturbations in one direction are always stronger than in another), the output wave will naturally carry a chiral marker;
- If there is a sustained, directional stress gradient around the node, its vibration mode will be "twisted" in that direction, and the output wave will exhibit a spiral morphology;
- When nodes form connections with each other, this chirality may be inherited into larger structures—quark rings, atoms, and molecules may all inherit the influence of this chiral preference.

In physical terms, this corresponds to:

- **Photon spin**: the electromagnetic field vector rotates along the propagation direction as the wave travels;
- **Neutrino chirality**: neutrinos are only left-handed, never right-handed;
- **Chiral molecules**: some molecules naturally exist in both left-handed and right-handed configurations, but nature uses only one of them.

## V. How Chirality Emerges from the Node Network

Consider a node connected to three neighboring nodes (like the peripheral nodes in a quark ring). The three neighbors send phase perturbations to the node from three different directions.

If there are slight asymmetries in the amplitude and phase of the perturbations from the three directions, the output wave emitted by the node will produce a net chiral preference through the superposition of contributions from the three directions—it will tend to be either left-handed or right-handed. This chiral preference is locked into the structure of the quark ring, and then inherited into atoms, molecules, and up to the level of life.

**Chirality is not "added on," but naturally produced by the node network in an asymmetric environment. It is not a property requiring additional explanation, but an inevitable consequence of the node network's geometry.**
