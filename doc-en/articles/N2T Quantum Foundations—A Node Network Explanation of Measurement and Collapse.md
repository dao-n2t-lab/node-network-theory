## I. The Geometric Definition of the Superposition State

### 1.1 The Superposition State in Standard Quantum Mechanics

In standard quantum mechanics, a system is in a superposition state:

$$|\psi\rangle = c_1|1\rangle + c_2|2\rangle$$

The system is simultaneously in a superposition of multiple eigenstates until measurement "forces" it to choose a definite state.

### 1.2 The Superposition State in the N2T Framework

In the N2T framework, the superposition state corresponds to:

**Multiple phase-synchronized paths in the system's node network being simultaneously active, with fixed relative phase differences between each path.**

For example, an electron standing wave on a shell-layer grid may simultaneously have multiple possible phase distribution modes—each mode corresponds to an "eigenstate." These modes coexist in the node network, forming a superposition state.

### 1.3 Geometric Representation of the Superposition State

In the node network, the geometric representation of the superposition state is:

- Multiple phase paths coexist on the same set of nodes;
- Each path has its specific phase distribution;
- The phase differences between paths are locked, forming a fixed interference pattern.

## II. Measurement: Phase Locking by an External Node Network

### 2.1 The Node Network of the Measurement Device

In the N2T framework, the measurement device is not an "observer" but an external node network with a large number of degrees of freedom.

When the system couples with the measurement device, edge connections are established between the system's node network and the device's node network. This connection is not "seeing" the system's state, but **strong phase locking**—locking the phase distribution of the system's node network together with the phase distribution of the device's node network.

### 2.2 The Complete Mechanism of Measurement

1. **System-device edge connection establishment**: Edge connections form between the system's node network and the measurement device's node network;
2. **Phase locking**: The phase distribution of the system's node network is "locked" onto a specific phase state of the device's node network;
3. **Suppression of other phase paths**: Once phase locking is complete, the system's other phase paths can no longer be maintained—they lack the phase support of the device's node network and begin to decay;
4. **Staticization of the node network**: The system's node network is "frozen" into a stable phase mode, corresponding to a definite eigenstate.

### 2.3 The Essence of Measurement Selection

In a superposition state, the multiple phase paths of the system's node network are not fixed—they continuously fluctuate. When the measurement device couples with the system, the device's node network itself also has thermal fluctuations. The device "selects" the mode that happens to best match the system's phase distribution at the moment of coupling.

## III. Collapse: The Geometric Necessity of Phase Locking

### 3.1 Collapse Is Not a "Mysterious Event"

In the N2T framework, collapse is not a mysterious, unexplainable event, but a geometric necessity of the node network:

1. After the system's node network establishes strong edge connections with the device's node network, the device's node network has a large number of degrees of freedom to "absorb" the system's phase perturbations;
2. The system's node network cannot maintain multiple phase paths simultaneously—because each path needs to match the device's phase state, and the device cannot match multiple paths at the same time;
3. The system selects one path; the phase information of the other paths diffuses through the edges into the device's node network, disappearing irreversibly.

### 3.2 The Irreversibility of Collapse

The irreversibility of collapse comes from:

| Factor | Node Network Manifestation |
|:---|:---|
| Phase information diffusion | Unselected phase information in the system's node network diffuses through edges into the device's node network and cannot be recovered |
| Degree of freedom gap | The device's node network has far more degrees of freedom than the system's node network; phase information is "diluted" to the point of being unextractable |
| Temporal directionality | The directionality of the phase locking process defines the arrow of time for collapse |

In the N2T framework, collapse is not a "wavefunction suddenly shrinking to a point," but the irreversible process in which the system's node network's phase distribution is "locked" into one state by the device's node network.

## IV. The Probabilistic Origin of Measurement Outcomes

### 4.1 Why Are the Outcomes Probabilistic?

In standard quantum mechanics, the probability of a measurement outcome is determined by the square of the wavefunction's amplitude. In the N2T framework, the origin of probability is as follows:

1. The "weight" of each phase path in a superposition state is determined by the stress distribution of that path in the node network;
2. Paths with lower stress are more likely to be locked by the device's node network;
3. The measurement outcome corresponds to the path that the system is locked onto at the moment of coupling.

### 4.2 Geometric Representation of Probability

In the N2T framework, the probability of a measurement outcome can be expressed using the principle of stress minimization:

$$P_i \propto e^{-\beta \cdot S_i}$$

where $S_i$ is the total stress of the $i$-th phase path, and $\beta$ is a constant related to the coupling strength with the device. Paths with lower stress have a higher probability of being locked.

**Probability is not "God rolling dice"—it is the statistical manifestation of the stress distribution of the node network.**
