## 项目简介

这是一个关于宇宙如何形成的思想试验，提出极简“节点+边”物理模型（Node Network Theory，N2T），以极少参数（节点数、节点间距、节点频率）推导出整个宇宙。

>在这个“极简”中蕴藏着涌现“复杂”的种子。

可以将宇宙的演化过程概括为：  
**宇宙初始化 → 形成物质 → 诞生生命 → 认识宇宙 → 建立模型 → 模拟宇宙**

人类正处在“认识宇宙、建立模型”这一演化阶段。

作者是一名资深IT工程师，最初的科研目标是：建立一套能够管理各种信息的系统。在经过近三十年的研究后，建立了 **“信息元模型+系统元模型+全生命周期管理算法”** 基础理论，并完成原型研发，实现产品落地。其核心思想是使用极简二元关系“继承”与“包含”，关联人类社会所有信息，实现信息的“唯一记录、全面关联”，本技术具备实现人类社会全域数字孪生的潜力。这个技术的底层就是 “信息节点+信息关系”（具体技术不在本项目讨论范围之内）。

在这套工程模型研发完成之后，发现该范式可以向外拓展，延伸用于构建宇宙模型。

这是一段从工程实践走向理论扩展的思想历程。

## 主要观点

1. **N2T 节点网络基底**  
    以"节点+边“作为底层基本单元，推演宇宙演化路径：节点网络、夸克、基本粒子、原子、分子、恒星、星系、中子星、黑洞、宇宙，进一步延伸至生命和社会系统。
2. **六层通用建模范式**  
    部件层｜架构层｜机制层｜事务层｜事件层｜信息层，既可描述宇宙中的物理对象，也可以描述具备环境识别、主动维持自身存续的系统对象（生命、人工智能、企业、国家等复杂组织）。
3. **自复制单元的跃迁**  
    宇宙演化中，可自我复制对象的涌现，是从单纯物理客体过渡到生命系统的临界环节。从化学复制子，到生命遗传编码，再到人造计算系统。
